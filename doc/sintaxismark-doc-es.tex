\section{Descripción general}

\texttt{sintaxismark} es un paquete de LaTeX para marcar constituyentes sintácticos, funciones gramaticales y núcleos directamente sobre texto corrido. Está pensado para materiales de gramática, ejercicios, diapositivas y análisis lingüísticos compactos.

La versión experimental 0.7.2 usa un único archivo principal, \texttt{sintaxismark.sty}. Ese archivo contiene tanto el modo clásico como el modo \texttt{grid}; por lo tanto, para usar la versión monolítica basta con copiar \texttt{sintaxismark.sty} al directorio del documento.

\section{Dos modos de uso}

\begin{enumerate}
  \item \textbf{Modo clásico}: usa superposiciones de TikZ con comandos como \verb|\spanline|, \verb|\openbox|, \verb|\tagbelow|, \verb|\SES|, \verb|\PVS|, \verb|\OD|, \verb|\MI|, etc. Es adecuado para ejemplos breves o para marcas manuales muy controladas.
  \item \textbf{Modo grid}: usa el entorno \verb|sintaxisgrid|. Lee una estructura anidada, extrae tokens, calcula saltos de línea y dibuja la anotación completa sobre una grilla. Está pensado para ejemplos largos o multilínea, porque evita diagonales cuando una marca atraviesa un salto de línea.
\end{enumerate}

El modo clásico se conserva por compatibilidad. El modo grid es experimental y requiere LuaLaTeX.

\section{Carga del paquete}

\begin{lstlisting}
\usepackage{sintaxismark}
\end{lstlisting}

Con \texttt{gb4e}, conviene cargar \texttt{gb4e} antes:

\begin{lstlisting}
\usepackage{gb4e}
\noautomath
\usepackage{sintaxismark}
\end{lstlisting}

También puede cargarse un esquema visual clásico:

\begin{lstlisting}
\usepackage[docencia]{sintaxismark}
\usepackage[impresion]{sintaxismark}
\usepackage[diapositivas]{sintaxismark}
\usepackage[publicacion]{sintaxismark}
\end{lstlisting}

Los esquemas ajustan el modo clásico. En esta versión experimental, el modo grid usa valores internos de separación que fueron aproximados a los valores del modo clásico, especialmente a los usos de \verb|liney|, \verb|boxd|, \verb|boxsep|, \verb|tagy| y \verb|nestedgap|.

\begin{lstlisting}
\documentclass{article}

\section{Modo grid experimental}

\subsection{Ejemplo básico}

\begin{lstlisting}
\begin{sintaxisgrid}[width=10cm,valign=base]
\SA{
  \SES{Juan}
  \PVS{
    vio
    \OD*{
      \MD{un}
      \N{tigre}
    }
  }
}
\end{sintaxisgrid}
\end{lstlisting}

La indentación no tiene valor estructural. La estructura está dada por los comandos y las llaves. El mismo ejemplo puede escribirse en una línea:

\begin{lstlisting}
\begin{sintaxisgrid}[width=10cm]
\SA{\SES{Juan}\PVS{vio \OD*{\MD{un}\N{tigre}}}}
\end{sintaxisgrid}
\end{lstlisting}

\subsection{Uso con \texttt{gb4e}}

\begin{lstlisting}
\begin{exe}
\ex
\begin{sintaxisgrid}[width=.92\linewidth,valign=base,yoffset=0pt]
\SA{\SES{Juan}\PVS{vio \OD*{\MD{un}\N{tigre}}}}
\end{sintaxisgrid}
\end{exe}
\end{lstlisting}

\verb|valign=base| alinea el entorno con la línea de base del ejemplo. Si el número de \texttt{gb4e} queda apenas alto o bajo, use \verb|yoffset|:

\begin{lstlisting}
\begin{sintaxisgrid}[width=.92\linewidth,valign=base,yoffset=0.2ex]
...
\end{sintaxisgrid}
\end{lstlisting}

\subsection{Opciones del entorno}

En la versión monolítica actual, las opciones estables del entorno son:

\begin{longtable}{ll}
\toprule
Opción & Función \\
\midrule
\verb|width=<dimensión>| & ancho disponible para calcular los cortes de línea \\
\verb|valign=base| & alinea con la línea de base, recomendado con \texttt{gb4e} \\
\verb|valign=t| & alineación superior \\
\verb|valign=c| & alineación centrada \\
\verb|valign=b| & alineación inferior \\
\verb|yoffset=<dimensión>| & ajuste vertical manual fino \\
\bottomrule
\end{longtable}

\subsection{Separación visual}

El renderizador grid usa valores internos ajustados para parecerse al modo clásico. En particular:

\begin{itemize}
  \item las líneas superiores se ubican con una separación comparable a \verb|liney| y \verb|labsep|;
  \item las cajas inferiores se ubican con una profundidad comparable a \verb|boxd| y \verb|boxsep|;
  \item las etiquetas inferiores simples usan una separación comparable a \verb|tagy|;
  \item los niveles anidados intentan reproducir el efecto de \verb|nestedgap| y de la reserva vertical automática del modo clásico.
\end{itemize}

Como el grid calcula una caja completa, no depende de \texttt{remember picture} ni requiere dos pasadas para ubicar las marcas. Las advertencias del tipo \texttt{Missing character: There is no U+000A in font nullfont} pueden aparecer en esta versión experimental y no impiden generar el PDF.
