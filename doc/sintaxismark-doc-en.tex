\section{Overview}

\texttt{sintaxismark} is a LaTeX package for annotating syntactic constituents, grammatical functions, heads, and spans directly over running text. It is intended for teaching materials, grammar handouts, slides, compact linguistic examples, and analyses where a full syntactic tree would be unnecessary or visually too heavy.

The package relies on TikZ overlays. It can draw lower open brackets, upper span lines, floating labels, underlines, arrowheads, nested markings, and manually split spans.

\section{Requirements}

The package loads or requires the following components:

\begin{itemize}
  \item \texttt{tikz}, with the \texttt{calc} and \texttt{arrows.meta} libraries;
  \item \texttt{xparse};
  \item \texttt{xcolor};
  \item \texttt{expl3};
  \item \texttt{varwidth}.
\end{itemize}

The package works well with \texttt{gb4e}, but \texttt{gb4e} is not required unless you want numbered linguistic examples.

Because the package uses TikZ's \texttt{remember picture} mechanism, documents should normally be compiled twice.

\section{Loading the package}

Place \texttt{sintaxismark.sty} in the same directory as your document or install it in your local TeX tree. Then load it in the preamble:

\begin{lstlisting}
\usepackage{sintaxismark}
\end{lstlisting}

You may also select a visual preset at load time:

\begin{lstlisting}
\usepackage[docencia]{sintaxismark}
\usepackage[impresion]{sintaxismark}
\usepackage[diapositivas]{sintaxismark}
\usepackage[publicacion]{sintaxismark}
\end{lstlisting}

The active schema can also be changed later:

\begin{lstlisting}
\setsintaxisschema{diapositivas}
\end{lstlisting}

\section{Minimal example}

\begin{lstlisting}
\documentclass{article}
\usepackage{gb4e}\noautomath
\usepackage[docencia]{sintaxismark}

\begin{document}

\begin{exe}
\ex \SES{Juan} \PVS{\NV{compró} \OD{manzanas}}.
\end{exe}

\end{document}
\end{lstlisting}

\section{Core commands}

\subsection{Lower open brackets: \texttt{\textbackslash openbox}}

\begin{lstlisting}
\openbox{OD}{Juan compró manzanas}
\end{lstlisting}

The first argument is the label. The second argument is the annotated text. Optional styling keys may be supplied in square brackets:

\begin{lstlisting}
\openbox[color=blue,linew=1pt,boxd=4ex]{OD}{manzanas}
\end{lstlisting}

\subsection{Upper span lines: \texttt{\textbackslash spanline}}

\begin{lstlisting}
\spanline{SES}{Juan} \spanline{PVS}{compró manzanas}
\end{lstlisting}

This command draws an upper horizontal line with vertical ends and a label above the span.

\subsection{Floating labels: \texttt{\textbackslash tagabove} and \texttt{\textbackslash tagbelow}}

\begin{lstlisting}
\tagabove{ST}{Juan compró manzanas}
\tagbelow{NN}{Juan}
\end{lstlisting}

\subsection{Underlining: \texttt{\textbackslash synul}}

\begin{lstlisting}
\synul{compró}
\end{lstlisting}

This is useful for marking heads or nuclei.

\section{Starred and unstarred forms}

Since version 0.6.19, many shortcuts have dual behavior:

\begin{itemize}
  \item the unstarred form uses a lower floating label, usually through \verb|\tagbelow|;
  \item the starred form uses a lower open bracket, through \verb|\openbox|.
\end{itemize}

\begin{lstlisting}
\OD{manzanas}     % lower tag + underline
\OD*{manzanas}    % lower open bracket

\MI{de lino}      % lower tag
\MI*{de lino}     % lower open bracket
\end{lstlisting}

\section{Long examples and wrapping}

For examples that need to wrap across lines, use \verb|\SMlinewrap|:

\begin{lstlisting}
\begin{exe}
\ex \SMlinewrap{El \MI{departamento de unos monoblocks deteriorados de tres pisos de color bordó} quedaba en la planta baja.}
\end{exe}
\end{lstlisting}

If a span should not be broken across a line boundary, use the no-break variants:

\begin{lstlisting}
\openboxNB{MI}{departamento de unos monoblocks deteriorados}
\spanlineNB{SES}{El departamento de unos monoblocks deteriorados}
\end{lstlisting}

\section{Manually split spans}

The command \verb|\breakspan| is useful when a span must be manually split into two visual parts. The first argument is rendered as a right-cut span; the second as a left-cut span.

\begin{lstlisting}
\breakspan
  {\SES{\MI{El departamento de unos monoblocks}}}
  {\SES{\MI{quedaba en la planta baja}}}
\end{lstlisting}

\section{Practical notes}

\begin{itemize}
  \item Compile twice when labels or lines appear misplaced on the first run.
  \item When using \texttt{gb4e}, load \texttt{gb4e} before \texttt{sintaxismark}.
  \item For long examples, prefer \verb|\SMlinewrap|, \verb|\openboxNB|, \verb|\spanlineNB|, or \verb|\breakspan|.
  \item Nested labels are automatically spaced using depth propagation, improved in version 0.6.21.
\end{itemize}

\section{Version notes}

Version 0.6.21 improves nested \verb|\tagbelow| spacing by chaining depth reports in the same way as \verb|\openbox|. This prevents nested lower tags from overlapping with each other or with labels in the following line.
