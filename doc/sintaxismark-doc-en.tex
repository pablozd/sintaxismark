\section{Overview}

\texttt{sintaxismark} is a LaTeX package for annotating syntactic constituents, grammatical functions, heads, and spans directly over running text. It is intended for teaching materials, grammar handouts, slides, compact linguistic examples, and analyses where a full syntactic tree would be unnecessary or visually too heavy.

The package has two complementary modes:

\begin{enumerate}
  \item \textbf{Classic mode}: the original TikZ-overlay system. It uses commands such as \verb|\spanline|, \verb|\openbox|, \verb|\tagbelow|, \verb|\SES|, \verb|\PVS|, \verb|\OD|, \verb|\MI|, etc. It draws directly over the current line.
  \item \textbf{Grid mode}: an experimental LuaLaTeX-only mode for long or multiline examples. It reads nested syntactic markup, extracts tokens, computes line breaks, and draws the analysis on a token grid. This prevents diagonal lines when a mark crosses a line break.
\end{enumerate}

Classic mode is preserved for compatibility. Grid mode adds an alternative workflow for longer and more configurable analyses.

\section{Requirements}

The package loads or requires the following components:

\begin{itemize}
  \item \texttt{tikz}, with the \texttt{calc} and \texttt{arrows.meta} libraries;
  \item \texttt{xparse};
  \item \texttt{xcolor};
  \item \texttt{expl3};
  \item \texttt{varwidth}.
\end{itemize}

Grid mode additionally requires LuaLaTeX, because layout computation is performed in Lua. If \texttt{sintaxisgrid} is used with pdfLaTeX or XeLaTeX, the package should raise an error.

The package works well with \texttt{gb4e}, but \texttt{gb4e} is not required unless numbered linguistic examples are needed.

Because classic mode uses TikZ's \texttt{remember picture} mechanism, documents should normally be compiled twice when classic overlays are used. Grid mode itself usually does not require two passes, but compiling twice is harmless when both modes are mixed.

\section{Loading the package}

Place \texttt{sintaxismark.sty} in the same directory as your document or install it in your local TeX tree. Then load it in the preamble:

\begin{lstlisting}
\usepackage{sintaxismark}
\end{lstlisting}

You may also select a visual preset at load time:

\begin{lstlisting}
\usepackage[docencia]{sintaxismark}
\usepackage[impresion]{sintaxismark}
\usepackage[diapositivas]{sintaxismark}
\usepackage[publicacion]{sintaxismark}
\end{lstlisting}

The active schema can also be changed later:

\begin{lstlisting}
\setsintaxisschema{diapositivas}
\end{lstlisting}

\begin{lstlisting}
\documentclass{article}
\usepackage{gb4e}\noautomath

\section{Core classic-mode commands}

\subsection{Lower open brackets: \texttt{\textbackslash openbox}}

\begin{lstlisting}
\openbox{OD}{Juan bought apples}
\end{lstlisting}

The first argument is the label. The second argument is the annotated text. Optional styling keys may be supplied in square brackets:

\begin{lstlisting}
\openbox[color=blue,linew=1pt,boxd=4ex]{OD}{apples}
\end{lstlisting}

\subsection{Upper span lines: \texttt{\textbackslash spanline}}

\begin{lstlisting}
\spanline{SES}{Juan} \spanline{PVS}{bought apples}
\end{lstlisting}

This command draws an upper horizontal line with vertical ends and a label above the span.

\subsection{Floating labels: \texttt{\textbackslash tagabove} and \texttt{\textbackslash tagbelow}}

\begin{lstlisting}
\tagabove{ST}{Juan bought apples}
\tagbelow{NN}{Juan}
\end{lstlisting}

\subsection{Underlining: \texttt{\textbackslash synul}}

\begin{lstlisting}
\synul{bought}
\end{lstlisting}

This is useful for marking heads or nuclei.

\section{Starred and unstarred forms}

Since version 0.6.19, many shortcuts have dual behavior:

\begin{itemize}
  \item the unstarred form uses a lower floating label, usually through \verb|\tagbelow|;
  \item the starred form uses a lower open bracket, through \verb|\openbox|.
\end{itemize}

\begin{lstlisting}
\OD{apples}     % lower tag + underline
\OD*{apples}    % lower open bracket

\MI{of linen}   % lower tag
\MI*{of linen}  % lower open bracket
\end{lstlisting}

\section{Long examples in classic mode}

For examples that need to wrap across lines, use \verb|\SMlinewrap|:

\begin{lstlisting}
\begin{exe}
\ex \SMlinewrap{The \MI{department of some deteriorated three-story blocks} was on the ground floor.}
\end{exe}
\end{lstlisting}

If a span should not be broken across a line boundary, use the no-break variants:

\begin{lstlisting}
\openboxNB{MI}{department of some deteriorated blocks}
\spanlineNB{SES}{The department of some deteriorated blocks}
\end{lstlisting}

The command \verb|\breakspan| is useful when a span must be manually split into two visual parts. The first argument is rendered as a right-cut span; the second as a left-cut span.

\begin{lstlisting}
\breakspan
  {\SES{\MI{The department of some blocks}}}
  {\SES{\MI{was on the ground floor}}}
\end{lstlisting}

\section{Experimental grid mode}

Grid mode is designed for long or multiline examples. Unlike classic mode, it does not draw each mark immediately. It first reads the whole environment body, extracts tokens, computes the range of each mark, determines line breaks according to the available width, and then draws the whole analysis.

This avoids diagonal lines when a \verb|\spanline| or \verb|\openbox| crosses a line break.

\subsection{Basic example}

\begin{lstlisting}
\begin{sintaxisgrid}[width=10cm]
\SA{
  \SES{Juan}
  \PVS{
    saw
    \OD*{
      \MD{a}
      \N{tiger}
    }
  }
}
\end{sintaxisgrid}
\end{lstlisting}

Vertical indentation has no structural value. It is only for readability. The same example can be written on one line:

\begin{lstlisting}
\begin{sintaxisgrid}[width=10cm]
\SA{\SES{Juan}\PVS{saw \OD*{\MD{a}\N{tiger}}}}
\end{sintaxisgrid}
\end{lstlisting}

The braces are what matters, because they express which constituent contains which material.

\subsection{Command interpretation inside \texttt{sintaxisgrid}}

Inside \verb|sintaxisgrid|, commands are not executed as in classic mode. They are interpreted structurally:

\begin{itemize}
  \item \verb|\SES|, \verb|\ST|, \verb|\SEC|, \verb|\PVS|, \verb|\PVC|, and \verb|\OS| produce upper spans.
  \item Starred forms such as \verb|\OD*|, \verb|\MI*|, or \verb|\COMP*| produce lower open boxes.
  \item Unstarred \verb|\OD| and \verb|\OI| produce lower underlined functions.
  \item \verb|\MD|, \verb|\N|, \verb|\NN|, \verb|\NV|, and similar labels produce simple lower tags.
\end{itemize}

\subsection{Use with \texttt{gb4e}}

\begin{lstlisting}
\begin{exe}
\ex
\begin{sintaxisgrid}[width=\linewidth]
\SA{\SES{Juan}\PVS{saw \OD*{\MD{a}\N{tiger}}}}
\end{sintaxisgrid}
\end{exe}
\end{lstlisting}

The environment baseline is intended to align the \texttt{gb4e} example number with the first line of the example. If a manual adjustment is needed, use \verb|yoffset|:

\begin{lstlisting}
\begin{sintaxisgrid}[width=\linewidth,yoffset=0.4ex]
...
\end{sintaxisgrid}
\end{lstlisting}

\subsection{Global grid options}

Global options are set with \verb|\sintaxismarksetup| and the \verb|grid/| prefix:

\begin{lstlisting}
\sintaxismarksetup{
  grid/lower-level-gap=0.75,
  grid/lower-label-sep=0.18,
  grid/token-pad-left=0.06,
  grid/token-pad-right=0.06
}
\end{lstlisting}

The main global keys are:

\texttt{grid/upper-leg} & length of upper vertical ends \\

\texttt{grid/lower-label-sep} & separation between lower box and label \\
\texttt{grid/tag-y-base} & base distance of simple lower tags \\

\subsection{Local environment options}

In a particular \verb|sintaxisgrid| instance, grid keys can be overridden without the \verb|grid/| prefix:

\begin{lstlisting}
\begin{sintaxisgrid}[width=10cm,lower-level-gap=0.50,token-pad-left=0.03]
...
\end{sintaxisgrid}
\end{lstlisting}

\subsection{Local mark options}

Options can also be supplied to a particular mark:

\begin{lstlisting}
\begin{sintaxisgrid}[width=10cm]
\SA{
  \SES[color=blue]{Juan}
  \PVS[color=black,arrow=right]{
    saw
    \OD*[color=red,no-leftend]{
      \MD[color=gray]{a}
      \N{tiger}
    }
  }
}
\end{sintaxisgrid}
\end{lstlisting}

These options affect only the mark on which they appear. Available local options include:

\begin{longtable}{ll}
\toprule
Local option & Function \\
\midrule
\texttt{color=<color>} & line and label color \\
\texttt{linecolor=<color>} / \texttt{line-color=<color>} & line color \\
\texttt{labelcolor=<color>} / \texttt{label-color=<color>} & label color \\
\texttt{textcolor=<color>} / \texttt{text-color=<color>} & alias for label color \\
\texttt{leftend=false} & remove the left vertical end \\
\texttt{rightend=false} & remove the right vertical end \\
\texttt{no-leftend} & alias for \texttt{leftend=false} \\
\texttt{no-rightend} & alias for \texttt{rightend=false} \\
\texttt{no-ends} & remove both vertical ends \\
\texttt{arrow=left} & left arrowhead \\
\texttt{arrow=right} & right arrowhead \\
\texttt{arrow=both} & arrowheads on both ends \\
\texttt{arrow=none} & no arrowheads \\
\texttt{leftarrow} & alias for \texttt{arrow=left} \\
\texttt{rightarrow} & alias for \texttt{arrow=right} \\
\texttt{leftrightarrow} & alias for \texttt{arrow=both} \\
\texttt{no-arrow} & alias for \texttt{arrow=none} \\
\bottomrule
\end{longtable}

\subsection{Example with local options}

\begin{lstlisting}
\begin{sintaxisgrid}[width=10cm]
\SA{
  \SES[no-ends,color=blue!60!black]{Juan}
  \PVS[arrow=both,color=orange!80!black]{
    saw
    \OD*[color=purple,rightend=false]{
      \MD{a}
      \N{tiger}
      \MI*[color=red!70!black,arrow=left]{
        with \COMP*[color=teal,no-ends]{sharp claws}

    }
  }

\end{sintaxisgrid}
\end{lstlisting}

\section{Practical notes}

\begin{itemize}
  \item Use LuaLaTeX when using \verb|sintaxisgrid|.
  \item Compile twice when classic-mode labels or lines appear misplaced on the first run.
  \item When using \texttt{gb4e}, load \texttt{gb4e} before \texttt{sintaxismark}.
  \item For long examples, grid mode is preferable. In classic mode, use \verb|\SMlinewrap|, \verb|\openboxNB|, \verb|\spanlineNB|, or \verb|\breakspan|.
  \item In grid mode, code indentation is not structural: only commands and braces are structural.
\end{itemize}

\section{Version notes}

Version 0.6.21 improves nested \verb|\tagbelow| spacing by chaining depth reports in the same way as \verb|\openbox|.

Version 0.6.23 adds experimental automatic splitting commands for plain text: \verb|\autospanline| and \verb|\autoopenbox|.

The experimental 0.7.0 grid mode introduces the \verb|sintaxisgrid| environment, LuaLaTeX-based grid layout, global options through \verb|\sintaxismarksetup{grid/...}|, and local mark options for color, arrows, and bracket endings.
